1เตรียมเครื่อง (ครั้งเดียว)Prepare the PC (once)

ต้องใช้ Ubuntu 24.04 + ROS 2 Jazzy (desktop) — ถ้าใช้ Windows ให้ติดตั้ง WSL2 + Ubuntu 24.04 (เปิดหน้าต่าง Gazebo/RViz ได้เลย) หรือข้ามไปใช้ Docker ในข้อ 7

You need Ubuntu 24.04 + ROS 2 Jazzy (desktop). On Windows use WSL2 + Ubuntu 24.04 (Gazebo/RViz windows work), or use Docker (see 7).

ถ้ามี ROS 2 Jazzy อยู่แล้ว ติดตั้งเครื่องมือเพิ่มแค่นี้:

If ROS 2 Jazzy is already installed, just add these tools:

sudo apt update
sudo apt install -y python3-colcon-common-extensions python3-rosdep unzip ros-jazzy-teleop-twist-keyboard
sudo rosdep init   # "already initialized" is fine
rosdep update
ยังไม่มี ROS 2? ติดตั้งตามคู่มือทางการ docs.ros.org → Jazzy → Ubuntu (deb) เลือกแบบ ros-jazzy-desktop
No ROS 2 yet? Follow the official guide docs.ros.org → Jazzy → Ubuntu (deb) and install ros-jazzy-desktop.

2แตกไฟล์ + Build workspaceUnzip + build the workspace

ดาวน์โหลด my_robot_ws.zip จากขั้น 3 (ปกติอยู่ใน ~/Downloads) แล้วรัน:

Download my_robot_ws.zip from step 3 (usually in ~/Downloads), then run:

cd ~ && unzip -o ~/Downloads/{N}_ws.zip
cd ~/{N}_ws
source /opt/ros/jazzy/setup.bash
rosdep install --from-paths src -y --ignore-src
colcon build --symlink-install
source install/setup.bash

ตรวจว่าได้ครบ 5 packages:

Check that all 5 packages are there:

ros2 pkg list | grep {P}_
ทุก terminal ใหม่ต้อง source ก่อนใช้งาน — ใส่ไว้ใน ~/.bashrc ครั้งเดียวจบ:
echo "source ~/{N}_ws/install/setup.bash" >> ~/.bashrc
Every new terminal must be sourced — add it to ~/.bashrc once:
echo "source ~/{N}_ws/install/setup.bash" >> ~/.bashrc

3จำลอง + ทำแผนที่ + นำทาง (คำสั่งเดียว)Simulate + map + navigate (one command)

ros2 launch {P}_bringup sim.launch.py
  1. Gazebo เปิดโกดัง TESR (โกดังเดียวกับในภารกิจของ Garage) และ RViz จะเห็นแผนที่ค่อย ๆ ขึ้น
  2. ใน RViz กด 2D Goal Pose แล้วคลิก-ลากบนแผนที่ → หุ่นวางเส้นทางและวิ่งไปเอง พร้อมทำแผนที่ไปด้วย
  3. อยากขับเอง เปิดอีก terminal แล้วรัน:
  1. Gazebo opens the TESR warehouse (the same one as the Garage missions) and RViz shows the map building up
  2. In RViz press 2D Goal Pose and click-drag on the map → the robot plans and drives there while mapping
  3. To drive by hand, open another terminal and run:
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args -p stamped:=true

ดูแค่ตัวหุ่นใน RViz (ไม่เปิด Gazebo):

Just look at the robot model in RViz (no Gazebo):

ros2 launch {P}_description display.launch.py

4บันทึกแผนที่ → นำทางด้วย AMCLSave the map → navigate with AMCL

ขับสำรวจจนแผนที่ครบ แล้ว (ในอีก terminal) บันทึกแผนที่:

Explore until the map is complete, then (in another terminal) save it:

ros2 run nav2_map_server map_saver_cli -f ~/{N}_map

ครั้งต่อไปใช้แผนที่เดิม (ไม่ทำแผนที่ใหม่) — ตั้งตำแหน่งเริ่มต้นด้วย 2D Pose Estimate ใน RViz ก่อนสั่ง Goal:

Next time reuse the saved map (no new mapping) — set the start pose with 2D Pose Estimate in RViz before sending goals:

ros2 launch {P}_bringup sim.launch.py slam:=false map:=$HOME/{N}_map.yaml

5ใช้กับหุ่นจริงRun the real robot

  1. ติดตั้ง workspace เดียวกันบนคอมพิวเตอร์ของหุ่น (ขั้น 1–2)
  2. ให้สิทธิ์พอร์ต USB/Serial แล้ว logout–login หนึ่งครั้ง: sudo usermod -aG dialout $USER
  3. เปิด driver ของเซนเซอร์ (LiDAR/กล้อง ตามรุ่นใน BOM) แล้วตรวจว่ามีข้อมูลเข้า: ros2 topic list และ ros2 topic hz /scan
  4. ทดสอบแบบไม่มีมอเตอร์ก่อน (mock) — ตรวจว่า controller ขึ้นครบ
  5. ยกล้อให้ลอยจากพื้น แล้วเปิดโหมดจริง ทดสอบขับด้วย teleop ช้า ๆ
  6. วางบนพื้น เปิดพร้อมการนำทาง
  1. Install the same workspace on the robot's computer (steps 1–2)
  2. Allow USB/serial access and log out/in once: sudo usermod -aG dialout $USER
  3. Start the sensor drivers (LiDAR/camera models from the BOM) and check data arrives: ros2 topic list, ros2 topic hz /scan
  4. Test without motors first (mock) — check the controllers come up
  5. Lift the wheels off the ground, start real mode and drive slowly with teleop
  6. Put it on the floor and start with navigation
# 4 · mock (no hardware)
ros2 launch {P}_bringup robot.launch.py hardware:=mock
ros2 control list_controllers
# 5 · real motors, wheels lifted
ros2 launch {P}_bringup robot.launch.py hardware:=real
# 6 · real robot + Nav2
ros2 launch {P}_bringup robot.launch.py hardware:=real nav:=true
⚠️ ทดสอบครั้งแรกทุกครั้ง: ยกล้อลอย ความเร็วต่ำ และมีคนพร้อมกด E-stop
⚠️ Every first test: wheels lifted, low speed, and someone ready on the E-stop.
